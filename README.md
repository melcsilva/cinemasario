# Movie Night Voting

Um projetinho simples e divertido que eu criei para o aniversário com minhas amigas 💖

O site permite que cada pessoa vote nos filmes que gostaria de assistir durante a nossa noite do cinema.  
Foi desenvolvido usando apenas HTML, CSS e JavaScript puro, focando em praticar manipulação do DOM, interatividade e organização visual.

## ✨ Funcionalidades

- Seleção de filmes
- Limite de votos
- Feedback visual com toast notifications
- Interface responsiva e divertida
- Envio dos votos pelo WhatsApp

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Sobre o projeto

Esse foi um daqueles projetos feitos mais por carinho e diversão do que por obrigação.  
Além de ajudar na organização da noite, também foi uma forma leve e criativa de praticar programação criando algo útil para pessoas próximas.
